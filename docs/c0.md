# c0 native recompiler

`c0` is the experimental native backend for `tbx`. It lowers decoded IR to a
self-contained C translation unit for modern platforms. Its standard is
behavioral fidelity, not byte-exact recompilation.

## Usage

```sh
tbx PROGRAM.EXE --emit-c -o program.c
cc program.c -lm -o program
```

GCC or Clang is required because generated GOSUB/RETURN code uses labels as
values. MinGW-w64 is supported on Windows; MSVC is not.

The generated runtime covers BASIC arithmetic and strings, DATA/READ,
sequential and random-access files, error handling, SUB/CALL, timers, and
graphics. Device and machine operations use documented host surrogates rather
than DOS hardware. The backend remains fail-loud for unsupported constructs.

## Shared runtime

The runtime can be built as a library:

```sh
make -C tbx/c0_runtime
tbx PROGRAM.EXE --emit-c --no-runtime -o program.c
cc program.c -Itbx/c0_runtime -Ltbx/c0_runtime -ltbrt -lm -o program
```

Use `make -C tbx/c0_runtime SDL=1` and `--sdl` for the SDL2 graphics backend.

## Validation

The c0 regression suite recompiles decoded fixtures and compares native output
with DOS behavior goldens:

```sh
TBX_C0=1 uv run pytest tests/tbx/test_c0.py -q
```

The backend and runtime are maintained on the `experimental/c0` branch and
are intentionally excluded from decoder release branches.
