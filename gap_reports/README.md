# Gap reports

This directory contains two complementary kinds of copyright-safe campaign
artifacts. Neither kind stores executable bytes.

- Date-stamped `*-baseline.json` files are generated by
  `python -m tbx.tools.scan_wild ... --report FILE`. They record the corpus
  fingerprint, normalized first-failure signatures, and per-file outcomes.
- `runtime-revision-assessments.json` is a manually curated evidence ledger for
  gaps that may come from a different Turbo Basic compiler or runtime-library
  revision. It is not regenerated by the scanner. Its `signatures` values use
  the same address-normalized vocabulary as scan reports where an active
  signature exists.

An assessment is not decoder authorization. Only entries with disposition
`closed` have enough evidence for an implemented mapping. Candidate entries
remain fail-loud until their `promotion_criteria` are satisfied.
